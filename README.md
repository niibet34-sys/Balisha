# Balisha.ru

Русскоязычная база знаний о Бали — статьи, ответы на вопросы, путеводитель и поиск.

- Тестовый сайт: https://balisha-preview.niibet34.workers.dev/
- Будущий основной домен: https://balisha.ru
- Статус: первая версия (V1).
- Репозиторий создан через GitHub-плагин ChatGPT.

Контент проверяется редакционно. Сайт пока не принимает платежи; поиск использует локальный индекс опубликованных статей, а не удалённую AI-модель.

Проект разворачивается на Cloudflare; первоначальный код и материалы добавляются в этот репозиторий.
