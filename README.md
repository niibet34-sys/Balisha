# Balisha.ru — путеводитель по Бали + персональный ИИ-эксперт

Коммерческая страница цифрового комплекта **«Путеводитель по Бали + промпт ИИ-эксперта Балиша»**. Полный PDF **не** включён в публичный репозиторий.

- Production после домена: https://balisha.ru
- Cloudflare Pages staging: https://balisha.pages.dev
- Сборка: `npm run build` → `dist/`
- Тестирование: `npm test`
- Разметка главной: `site/index.html`
- Стили/интерактивность: `site/assets/landing.css`, `site/assets/landing.js`
- Только ознакомительный фрагмент: `site/samples/balisha-preview.pdf`
- Настройка внешнего HTTPS checkout: `site/config/commerce.json` (по умолчанию `mode: preview`)
- Чек-лист перед реальными продажами: `SALES_LAUNCH_CHECKLIST.md`

Текстовый логотип Balisha.ru сохраняется без изменения шрифта Grand Hotel. Все страницы базы знаний в `site/stati/`, `site/temy/` сохранены для будущего развития; сейчас основной публичный маршрут — лендинг.

Примечание по материалам: публичные изображения страниц и фотографии извлечены из предоставленного владельцем PDF `Bali_Guide_RU_v2.pdf`, 410 страниц, 8 октября 2026; юридическая проверка встроенных изображений в книге остаётся отдельной задачей.
