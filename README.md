# Balisha.ru

Минималистичная русскоязычная база знаний о Бали.

Тест: https://balisha-preview.niibet34.workers.dev/

Исходники первой версии доступны в виде архива из разговора с ChatGPT. Текущая версия в GitHub — полный статический снимок развернутого сайта с HTML, CSS, JS и поисковым индексом; дальнейшие изменения публикуются через Cloudflare Pages.

Cloudflare Pages: команда сборки `npm run build`, каталог `dist`.
