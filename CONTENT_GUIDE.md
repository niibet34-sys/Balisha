# Редакционная работа с Balisha V1

Текущая версия на GitHub сохраняет **полный статический снимок** сайта: файлы находятся в каталоге `site/`.
Их можно редактировать и дополнять без платных сервисов.

## Добавить статью
1. Создать `site/stati/<slug>/index.html`, сохранив структуру HTML существующей статьи.
2. Добавить ссылку в соответствующий каталог `site/temy/<category>/index.html`.
3. Добавить запись в `site/search-index.json` с `title, slug, path, description, answer, category, keywords, faqs, heading`.
4. Добавить URL с датой изменения в `site/sitemap.xml`.
5. Проверить заголовок, короткий ответ, редакционные источники, дату актуальности, canonical и JSON-LD.
6. Запустить `npm test` и `npm run build`.

## Безопасность качества
Не придумывать факты про визы, разрешения на вождение, страховку, погоду, цены и медицину.
Отделять рекламу от редакционного ответа. Указывать источник и дату проверки.

## Важно для следующего этапа
Этот репозиторий содержит **готовые исходные HTML/CSS/JS-файлы**, извлечённые из действующей сборки V1.
Более удобный генератор сайта из структурированных публикаций существует отдельно в архиве `Balisha_v1_source.zip` из чата. При переходе к поточному выпуску сотен статей стоит перенести генератор в репозиторий, чтобы не редактировать HTML вручную.
