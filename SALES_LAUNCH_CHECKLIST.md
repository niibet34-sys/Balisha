# Balisha — запуск продаж: обязательные условия

Ветка v3 выпускается **без оплаты и без публичной выдачи платных материалов**. Публично доступен только `site/samples/balisha-preview.pdf`: 13 выборочных страниц из подтверждённого 410-страничного путеводителя.

## Перед запуском
1. Утвердить цену, валюту и провайдера HTTPS-checkout (Boosty/VK/иной, решение за владельцем).
2. Утвердить финальный коммерческий PDF, обложку/брендинг Balisha или текущее название Bali Discount и права на изображения. Сейчас используется точная обложка `Bali_Guide_RU_v2.pdf`, без перекрашивания или замены надписей.
3. Зафиксировать продавца/реквизиты/поддержку/сроки выдачи/условия возврата/обновлений/политику конфиденциальности. Не подменять пробелы фантазией.
4. Загружать полный PDF, TXT-промпт и инструкцию **только в защищённое хранилище** выбранного провайдера или закрытое хранилище с подписанными ссылками; не коммитить файлы на GitHub и не класть в `site/`, `dist/`, public R2 или Pages assets.
5. Автоматическую выдачу делать на основании подтверждённого статуса оплаченного заказа на стороне платёжного сервиса, а не параметров redirect success-страницы или браузера. Повторные webhooks обрабатывать идемпотентно, после выдачи журналировать ID заказа (без лишних персональных данных).
6. Предусмотреть безопасную повторную выдачу по номеру заказа через поддержку/провайдера и тестовую покупку: success/cancel, повтор webhook, неуспешная оплата, недоставка письма.
7. После подтверждения платежного провайдера установить `site/config/commerce.json` с `mode: "live"` и точным HTTPS-checkout URL. Кнопка не принимает карту на сайте, а открывает провайдера. **Продажу учитывает только подтверждение заказа**, не клик.
8. Проверить индексацию основного домена, отключить конфликтующий Worker route после миграции к Pages, сохранить `pages.dev` под noindex.
9. Подключить аналитику с уважением к законодательству/согласию; события `balisha:analytics` в JS — лишь готовые точки интеграции. Ничего не отправляется внешним сервисам до установки аналитики. Подтверждённый `purchase` — только по verified webhook либо API провайдера.

## Внешние изображения
- Страница использует только страницы и снимки из `Bali_Guide_RU_v2.pdf`, предоставленного владельцем. Их отдельный аудит лицензий *ещё не завершён*. За пределами галереи выведены реальные фотографии из PDF; права необходимо подтвердить до рекламного запуска.
- Шрифты остаются прежними: Grand Hotel для слова `Balisha.ru` без изменения.

## Замена страниц
- `site/assets/previews/cover.webp` — настоящая обложка последней книги.
- `site/assets/previews/page-{номер}-thumb.webp` и `-full.webp` — реальные страницы галереи.
- `site/samples/balisha-preview.pdf` — бесплатный 13-страничный ознакомительный фрагмент (реальные, выборочные страницы; не издавать под видом полного PDF).
- Все оригинальные платные материалы остаются ВНЕ GitHub / public Pages.
