ОСТАЛИСЬ ВОПРОСЫ?

Всё по делу.

Ответы на вопросы о цифровом путеводителе и бонусном ИИ-помощнике.

Что именно входит в комплект?

Большой PDF-путеводитель по Бали (410 страниц), промпт для создания ИИ-эксперта Балиша и пошаговая инструкция по его запуску.

Нужно ли отдельное приложение Balisha?

Нет. Для Балиши достаточно совместимого ИИ-чата, в котором можно использовать свой промпт. Книгу можно читать обычной программой для PDF.

Нужна ли платная подписка на ИИ?

Не обязательно, если выбранный сервис позволяет использовать промпты бесплатно. Ограничения по сообщениям, функциям, веб-поиску и моделям определяет сам сервис. Подписка на сторонний ИИ не включена.

Балиша работает без путеводителя?

Да. Это самостоятельный ИИ-эксперт. Загружать книгу в чат необязательно. По желанию можно использовать оба инструмента отдельно или вместе.

Может ли Балиша проверять актуальную информацию?

Если выбранный ИИ-чат предоставляет доступ к интернет-поиску и вы включили соответствующую функцию. Сам по себе промпт не предоставляет интернет, геолокацию или карты.

Можно ли читать путеводитель без интернета?

Да, скачанный PDF доступен офлайн на вашем устройстве. Для перехода по внешним ссылкам и работы ИИ-чата может потребоваться подключение.

Как я получу файлы после оплаты?

Продажи ещё не запущены. При подключении платёжного сервиса здесь появится подтверждённый способ автоматического получения комплекта после оплаты.

Будут ли обновления и можно ли вернуть покупку?

Условия обновлений и возвратов будут опубликованы до начала продаж вместе с юридической информацией о продавце. Сейчас они не установлены.
